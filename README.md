ventana de incion de sesion (login)
---El sistema debe de tener una pantalla de incio de sesion
---Para este proyecto, el inicio de seion se hara con datos preestablecidos 

ventana de boletos
---El sistema debe permitir al empleado seleccionar la pelicula, el horario y la sala
